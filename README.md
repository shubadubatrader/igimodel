# ИГИ → «Грунт» ЛИРА-САПР

Локальная переносимая программа для подготовки модели грунта по исходным материалам инженерно-геологических изысканий. Чертежи и PDF никуда не отправляются: DWG/DXF, PDF, OCR и Excel обрабатываются на компьютере без облака и без ИИ.

## Что подаётся на вход

1. План инженерно-геологических скважин (`DWG`, `DXF` или `PDF`).
2. Инженерно-геологические колонки (`DWG`, `DXF` или `PDF`).
3. Таблица нормативных и расчётных характеристик грунтов (`DWG`, `DXF` или `PDF`). Если её не выбрать, откроется резервный редактируемый справочник.
4. Необязательная ведомость координат и отметок (`PDF`, `PNG`, `JPG`, `TIFF`, `BMP` или `WEBP`). Если она задана, X/Y/Z берутся из неё, а схема используется для контроля. Если отдельной строки в ведомости нет, координаты этой скважины берутся со схемы. При отсутствии плана достаточно ведомости и файла колонок.

Файлы могут иметь другое число скважин, другие абсолютные координаты, поворот, расположение листов и небольшие отличия подписей. Программа ищет смысловые подписи, геометрию скважин, заголовки и числовые последовательности, а не фиксированные номера ячеек или координаты примера.

## Результат

- Excel-файл с двумя листами: `Характеристики грунтов` и `Скважины`.
- Кнопки копирования обоих массивов прямо в буфер обмена для вставки в соответствующую таблицу программы «Грунт» ЛИРА-САПР.
- Протокол распознавания с предупреждениями о неоднозначных или различающихся данных.

Публично описанный рабочий процесс ЛИРА-САПР использует вставку массивов из Excel. Документированного открытого формата отдельного файла модели грунта в изученной статье нет, поэтому программа не записывает неподтверждённый внутренний формат ЛИРА. Кнопка копирования фактически убирает обязательный промежуточный ручной этап с Excel, сохраняя Excel как проверяемый результат.

## Запуск переносимой версии

Откройте `IGIModel.exe` из папки `dist\IGIModel`. Установка Python, AutoCAD, Excel или Tesseract на целевом компьютере не требуется. Папку `IGIModel` нужно переносить целиком.

1. Выберите план или ведомость координат, файл колонок и при наличии таблицу характеристик. Можно выбрать и план, и ведомость одновременно.
2. Нажмите **Распознать**.
3. Проверьте вкладки и протокол.
4. Проверьте X/Y. Автоматически определяется поворот и относительное расположение. Если проектная точка начала координат не обозначена в исходнике, укажите номер одной известной скважины и её X/Y, затем нажмите **Привязать начало координат**.
5. Сохраните профиль, чтобы применять ту же систему координат и правила к следующим файлам этого проекта.
6. Экспортируйте Excel либо скопируйте таблицу и вставьте её в ЛИРА-САПР с первой ячейки (`Ctrl+V`).

Профиль `profiles\inbox_example.json` калиброван по примеру `Inbox` и воспроизводит координаты из `2.png`. Профиль `profiles\automatic.json` не содержит проектной привязки и подходит для первичного анализа новых объектов.

## PDF

- Векторный PDF: текст и линии читаются напрямую.
- Сканированный PDF: автоматически используется встроенный локальный Tesseract OCR (`rus+eng`). Для скана особенно важны проверка таблиц и калибровка масштаба/координат, поскольку PDF может содержать только координаты листа.
- Ведомость в виде изображения: сетка таблицы выделяется алгоритмически, строки распознаются локальным OCR по отдельности. Программа восстанавливает очевидно пропущенные OCR десятичные разделители и обязательно отмечает такие строки в протоколе.

## Приоритет координат

1. Ведомость координат и отметок — основной источник X/Y/Z.
2. План — контроль положения и резерв для отсутствующих в ведомости скважин.
3. Колонки — источник слоёв и мощностей; отметка из колонки используется, только если она не распознана в ведомости.

Для ведомостей МСК программа автоматически проверяет по плану, соответствует ли геодезический X вертикальной оси CAD, а геодезический Y горизонтальной. Если расхождение координат ведомости и схемы превышает 0,5 м, оно выводится в протокол, но в результат всё равно попадает ведомость.

## Проверки и единицы

- Модуль деформации из МПа переводится в т/м².
- Сцепление из кПа переводится в т/м².
- Влажность из процентов переводится в доли единицы.
- `K` для кодов `Ls/Cs` и `Lp/Cp` интерполируется по `IL`; код можно отредактировать по встроенному справочнику.
- Мощности проверяются по накопленной глубине, отметка колонки имеет приоритет перед подписью на плане. В примере для скважины 66853 исходники содержат 103,02 на плане и 103,22 в колонке; в результат берётся 103,22 и создаётся предупреждение.

Любую распознанную ячейку можно изменить двойным щелчком до экспорта.

## Сборка из исходного кода

Требуется Python 3.12 и зависимости из `requirements.txt`, а также `pyinstaller`.

```powershell
python -m pip install -r requirements.txt pyinstaller
.\build_portable.ps1 -Python python
```

Сторонние компоненты и их лицензии перечислены в `THIRD_PARTY_NOTICES.md`. Исходный код включается в переносимую папку `source`.
